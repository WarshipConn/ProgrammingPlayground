Problem & PurposeThe Goal: Generate a uniformly random derangement (a one-to-one mapping where no element pairs with itself, $i \neq \text{partner}[i]$) across all valid configurations (both single-cycle and multi-cycle loops).The Constraint: Must run in strict, deterministic $O(N)$ time without relying on retries or rejection loops (like Rejection Sampling).Why Sattolo's Isn't Enough: Sattolo's algorithm runs in $O(N)$ time, but it only generates single-cycle derangements (e.g., $A \to B \to C \to A$), completely missing multi-cycle derangements (e.g., $A \leftrightarrow B$ and $C \leftrightarrow D$).2. Core Intuition & Mathematical BasisMPP builds the derangement element-by-element without ever producing an invalid assignment.At each step for an unmatched element $i$, the algorithm chooses a target $j$ and faces a binary structural decision:Option A (Close a 2-Cycle): Set $i \leftrightarrow j$. Both elements are completely satisfied and removed from the active pool.Option B (Extend a Chain): Set $i \to j$, but leave $j$'s outgoing link open for a future step (meaning $j \not\to i$).To ensure that all $!N$ derangements are sampled with exact equal probability $\frac{1}{!N}$, MPP uses the sub-derangement counts ($D_k$) to dynamically weight the decision to close a 2-cycle:$$P(\text{close 2-cycle}) = \frac{D_{u-2}}{(u - 1) D_{u-1} + D_{u-2}}$$(where $u$ is the count of currently unmatched elements, and $D_k = (k - 1)(D_{k-1} + D_{k-2})$).3. Step-by-Step Algorithm ExecutionStep 1: PrecomputationCompute the derangement counts $D_0, D_1, \dots, D_N$ in $O(N)$ time using the recurrence relation:$$D_0 = 1, \quad D_1 = 0, \quad D_k = (k - 1)(D_{k-1} + D_{k-2})$$Step 2: Tracking SetupMaintain a set or list of unmatched indices (initialized to $0, 1, \dots, N-1$) and an output array initialized with empty mappings.Step 3: Sequential ProcessingIterate through index $i = 0$ to $N-1$:Check Availability: If element $i$ was already assigned during an earlier 2-cycle step, skip to $i+1$.Pick Target: Select a candidate target $j$ uniformly at random from all current unmatched items excluding $i$.Evaluate Probability: Calculate $P(\text{close}) = \frac{D_{u-2}}{(u-1)D_{u-1} + D_{u-2}}$, where $u = \vert{}\text{unmatched}\vert{}$.Branching Decision:With probability $P(\text{close})$ (Option A):Form the 2-cycle: $i \to j$ and $j \to i$.Remove both $i$ and $j$ from unmatched.With probability $1 - P(\text{close})$ (Option B):Assign $i \to j$.Remove only $i$ from unmatched ($j$ remains open to point elsewhere in a future step).Step 4: OutputMap the resulting indices back to your original elements (e.g., letters, people, objects).4. Key TakeawaysStrict $O(N)$ Time: Exactly $N$ decisions are made; no retries, no infinite loops.Uniformity: Generates every valid derangement (single-cycle, multi-cycle, mixed) with exact probability $\frac{1}{D_N}$.Restricted Cycle Generator: MPP can be viewed as an algorithm that generates a random cycle decomposition restricted to cycles of length $L \ge 2$ (forbidding self-pointers/1-cycles).
